# 终端乱码修复方案

## 问题原因
终端字符编码设置为 `LANG=C`，导致中文和特殊符号显示为乱码。

## 已完成的修复

### 1. 环境变量设置
已添加以下配置到 `~/.bashrc`：

```bash
# Fix terminal encoding for UTF-8 display
export LANG=en_US.UTF-8
export LC_ALL=en_US.UTF-8
export LANGUAGE=en_US:en
```

### 2. 立即生效
```bash
source ~/.bashrc
```

## VS Code 额外配置（如果仍有乱码）

### 方法1: 修改 VS Code 设置
在 VS Code 设置中添加：

1. 打开设置 (Ctrl+,)
2. 搜索 `terminal.integrated.env.linux`
3. 添加：
```json
{
  "terminal.integrated.env.linux": {
    "LANG": "en_US.UTF-8",
    "LC_ALL": "en_US.UTF-8"
  }
}
```

### 方法2: 修改终端字体
1. 打开设置 (Ctrl+,)
2. 搜索 `terminal.integrated.fontFamily`
3. 设置为支持Unicode的字体：
   - `'Cascadia Code', 'DejaVu Sans Mono', monospace`
   - 或 `'Noto Sans Mono', 'Source Code Pro', monospace`

### 方法3: 重启 VS Code
完成上述设置后，重启 VS Code 使配置生效。

## 验证修复

打开新终端，运行：
```bash
# 检查locale
locale

# 应该看到：
# LANG=en_US.UTF-8
# LC_ALL=en_US.UTF-8

# 测试显示
echo "✅ UTF-8 正常"
echo "测试中文：你好世界"
```

## 快速修复命令

如果新终端仍有乱码，手动运行：
```bash
export LANG=en_US.UTF-8
export LC_ALL=en_US.UTF-8
```

## setup.sh 使用说明

修复乱码后，正确使用 setup.sh：

```bash
# 1. 设置 OpenAI API Key
export KEY="sk-your-openai-api-key"

# 2. 运行 setup.sh (不要用 sudo)
./setup.sh

# 3. 等待 Docker 镜像构建完成

# 4. 运行 fuzzing
./run.sh 5 10 kamailio chatafl
```

**重要提醒：**
- ❌ 不要用 `sudo ./setup.sh` - sudo会丢失环境变量
- ✅ 直接运行 `./setup.sh` 即可
- KEY 必须在运行 setup.sh 前设置
