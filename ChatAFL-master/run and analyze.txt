停掉所有的容器
docker ps -q | xargs -r docker stop && docker ps -a -q -f status=exited | xargs -r docker rm
删除所有已经停止的容器
docker ps -a -q -f status=exited | xargs -r docker rm
帮我清除掉TAG为<none> 的镜像
docker images -a --format '{{.ID}} {{.Repository}}:{{.Tag}}' | awk '/<none>:/ {print $1}' | sort -u | xargs -r docker rmi -f
清除掉所有的镜像
docker rmi -f $(docker images -aq)
