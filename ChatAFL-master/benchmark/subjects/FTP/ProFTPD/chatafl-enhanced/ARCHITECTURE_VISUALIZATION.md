## 重构后架构（遵循开闭原则）

```
┌──────────────────────────────────────────────────────────────────────┐
│                           afl-fuzz.c                                 │
│                        (10,900 lines)                                │
│  ┌────────────────────────────────────────────────────────────────┐ │
│  │  #include "afl-fuzz-plugin.h"  ← 唯一的插件接口                │ │
│  │                                                                 │ │
│  │  main() {                                                       │ │
│  │    // 初始化插件系统                                             │ │
│  │    setup_plugins(NULL);                                        │ │
│  │    PLUGIN_HOOK_INIT(...);                                      │ │
│  │                                                                 │ │
│  │    while (fuzzing) {                                            │ │
│  │      // 执行后钩子 - 插件自动被调用                              │ │
│  │      PLUGIN_HOOK_POST_EXEC(buf, len, ...);                     │ │
│  │                                                                 │ │
│  │      // 其他钩子点                                               │ │
│  │      PLUGIN_HOOK_COVERAGE_UPDATE(...);                         │ │
│  │      PLUGIN_HOOK_STATE_TRANSITION(...);                        │ │
│  │    }                                                            │ │
│  │                                                                 │ │
│  │    // 清理插件系统                                               │ │
│  │    cleanup_plugins();                                          │ │
│  │  }                                                              │ │
│  └────────────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────────┘
                              │
                              │ 通过钩子接口
                              ▼
┌──────────────────────────────────────────────────────────────────────┐
│                       plugin-manager.c                               │
│                      (插件调度中心)                                   │
│  ┌────────────────────────────────────────────────────────────────┐ │
│  │  plugin_invoke_hook(hook_type, hook_data) {                    │ │
│  │    for (each registered plugin in priority order) {            │ │
│  │      result = plugin->on_hook(hook_type, hook_data);           │ │
│  │      // 聚合决策                                                 │ │
│  │    }                                                            │ │
│  │  }                                                              │ │
│  └────────────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────────┘
              │                   │                   │
              │ Priority 100      │ Priority 90       │ Priority 80
              ▼                   ▼                   ▼
┌───────────────────┐  ┌───────────────────┐  ┌───────────────────┐
│ plugin-verifier.c │  │plugin-scheduler.c │  │  plugin-cegar.c   │
│                   │  │                   │  │                   │
│  ┌─────────────┐  │  │  ┌─────────────┐  │  │  ┌─────────────┐  │
│  │ Plugin Data │  │  │  │ Plugin Data │  │  │  │ Plugin Data │  │
│  │  • checks   │  │  │  │  • states   │  │  │  │  • patches  │  │
│  │  • rejects  │  │  │  │  • graph    │  │  │  │  • retries  │  │
│  └─────────────┘  │  │  └─────────────┘  │  │  └─────────────┘  │
│         │         │  │         │         │  │         │         │
│         ▼         │  │         ▼         │  │         ▼         │
│  ┌─────────────┐  │  │  ┌─────────────┐  │  │  ┌─────────────┐  │
│  │  verifier.c │  │  │  │state-       │  │  │  │  cegar-     │  │
│  │  verifier.h │  │  │  │scheduler.c/h│  │  │  │refinement.c │  │
│  └─────────────┘  │  │  └─────────────┘  │  │  └─────────────┘  │
└───────────────────┘  └───────────────────┘  └───────────────────┘

✅ 优势：
  • 零耦合：核心不知道插件内部实现
  • 封装性：每个插件管理自己的状态
  • 干净代码：无#ifdef分裂
  • 易扩展：添加插件无需修改核心
  • 易测试：插件可独立测试
```

## 钩子调用流程

```
┌─────────────────────────────────────────────────────────────┐
│ 1. afl-fuzz.c 触发钩子                                       │
└─────────────────────────────────────────────────────────────┘
                        │
                        │ PLUGIN_HOOK_POST_EXEC(...)
                        ▼
┌─────────────────────────────────────────────────────────────┐
│ 2. plugin_manager.c 分发到所有已注册插件                     │
│    按优先级排序执行                                          │
└─────────────────────────────────────────────────────────────┘
         │                    │                    │
         │ Priority 100       │ Priority 90        │ Priority 80
         ▼                    ▼                    ▼
┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│ Verifier     │    │ Scheduler    │    │ CEGAR        │
│              │    │              │    │              │
│ • 验证消息    │    │ • 更新状态图  │    │ • 检测拒绝    │
│ • 检查格式    │    │ • 检测平台期  │    │ • LLM修复     │
│              │    │              │    │              │
│ return:      │    │ return:      │    │ return:      │
│ CONTINUE     │    │ CONTINUE     │    │ ADD_TO_QUEUE │
└──────────────┘    └──────────────┘    └──────────────┘
         │                    │                    │
         └────────────────────┴────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│ 3. plugin_manager.c 聚合决策                                 │
│    如果任何插件返回 ADD_TO_QUEUE，则添加到队列                │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│ 4. afl-fuzz.c 执行决策                                       │
│    根据插件决策继续fuzzing                                    │
└─────────────────────────────────────────────────────────────┘
```

## 插件生命周期

```
程序启动
   │
   ├─> plugin_register()        ← 注册Verifier插件
   ├─> plugin_register()        ← 注册Scheduler插件
   ├─> plugin_register()        ← 注册CEGAR插件
   │
   ├─> plugin_system_init()     ← 初始化插件系统
   │      │
   │      ├─> verifier_plugin_init()    ← 初始化各插件
   │      ├─> scheduler_plugin_init()
   │      └─> cegar_plugin_init()
   │
   ├─> HOOK_INIT                ← 初始化钩子
   ├─> HOOK_PRE_FUZZ            ← 预fuzzing钩子
   │
   ├─> [Fuzzing Loop]
   │      │
   │      ├─> HOOK_PRE_EXEC     ← 每次执行前
   │      ├─> HOOK_POST_EXEC    ← 每次执行后
   │      ├─> HOOK_STATE_TRANSITION  ← 状态转换
   │      ├─> HOOK_COVERAGE_UPDATE   ← 覆盖率更新
   │      ├─> HOOK_CRASH_FOUND       ← 发现崩溃
   │      └─> HOOK_PERIODIC          ← 定期触发
   │
   ├─> HOOK_CLEANUP             ← 清理钩子
   │
   ├─> plugin_system_cleanup()  ← 清理插件系统
   │      │
   │      ├─> verifier_plugin_cleanup()
   │      ├─> scheduler_plugin_cleanup()
   │      └─> cegar_plugin_cleanup()
   │
   └─> 程序退出
```
