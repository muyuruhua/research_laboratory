┌─────────────────────────────────────────────────────────┐
│ 🚀 首次启动（仅需一次）                                   │
└─────────────────────────────────────────────────────────┘
  ./dev-sync.sh start
  
  ✓ 创建开发容器
  ✓ 挂载当前目录到容器
  ✓ 容器保持运行状态

┌─────────────────────────────────────────────────────────┐
│ 🔄 日常开发循环                                          │
└─────────────────────────────────────────────────────────┘
  1. 在 VS Code 修改代码（afl-fuzz.c, chat-llm.c ...）
  
  2. 重新编译：
     ./dev-sync.sh sync       # 完整编译（~15秒）
     ./dev-sync.sh rebuild    # 快速编译（~8秒）
  
  3. 测试：
     ./dev-sync.sh shell      # 进入容器
     ./afl-fuzz -h            # 验证二进制

┌─────────────────────────────────────────────────────────┐
│ 🎯 推荐工作流                                            │
└─────────────────────────────────────────────────────────┘
  # 早上启动
  ./dev-sync.sh start
  
  # 开发过程（重复）
  vim afl-fuzz.c              # 修改代码
  ./dev-sync.sh sync          # 编译
  ./dev-sync.sh shell         # 测试
  
  # 晚上下班
  ./dev-sync.sh stop          # 停止（数据保留）

┌─────────────────────────────────────────────────────────┐
│ 🔧 常用命令                                              │
└─────────────────────────────────────────────────────────┘
  ./dev-sync.sh start         启动开发容器
  ./dev-sync.sh sync          同步+重编译
  ./dev-sync.sh rebuild       快速重编译
  ./dev-sync.sh shell         进入容器
  ./dev-sync.sh stop          停止容器
  ./dev-sync.sh logs          查看日志
  ./dev-sync.sh watch         自动监控模式

┌─────────────────────────────────────────────────────────┐
│ ⚡ 自动监控模式（高级）                                   │
└─────────────────────────────────────────────────────────┘
  # 安装依赖（仅首次）
  sudo apt-get install inotify-tools
  
  # 启动监控（保存 .c/.h 时自动编译）
  ./dev-sync.sh watch
  
  # 按 Ctrl+C 停止

┌─────────────────────────────────────────────────────────┐
│ 💡 性能对比                                              │
└─────────────────────────────────────────────────────────┘
  传统 setup.sh:  5-10 分钟  ❌ 慢
  docker cp:      1-2 分钟   ⚠️  手动
  dev-sync:       10-15 秒   ✅ 推荐

┌─────────────────────────────────────────────────────────┐
│ 🐛 故障排查                                              │
└─────────────────────────────────────────────────────────┘
  容器未运行:
    ./dev-sync.sh start
  
  编译失败:
    ./dev-sync.sh shell
    make clean && make 2>&1 | tee error.log
  
  代码未同步:
    # 检查挂载
    docker inspect chatafl-enhanced-dev | grep Mounts
  
  重置一切:
    docker stop chatafl-enhanced-dev
    docker rm chatafl-enhanced-dev
    make clean
    ./dev-sync.sh start

┌─────────────────────────────────────────────────────────┐
│ 📂 文件结构                                              │
└─────────────────────────────────────────────────────────┘
  宿主机:  ~/ChatAFL-Enhanced/afl-fuzz.c
            ↕️  (实时双向同步)
  容器内:  /opt/aflnet/afl-fuzz.c
  
  编译产物也会同步：
  容器编译 → afl-fuzz → 宿主机立即可用

┌─────────────────────────────────────────────────────────┐
│ 🎓 最佳实践                                              │
└─────────────────────────────────────────────────────────┘
  1. 容器保持长期运行（几天/几周）
  2. 只在需要时 stop（节省资源）
  3. 提交前运行完整测试：
     ./dev-sync.sh sync
     ./dev-sync.sh shell
     ./run_comparison.sh 1 1 HTTP chatafl_enhanced
  
  4. 备份实验数据（容器外）：
     cp -r output/ ~/backup/

┌─────────────────────────────────────────────────────────┐
│ 🔒 安全注意事项                                          │
└─────────────────────────────────────────────────────────┘
  - Volume 挂载的文件容器/宿主机共享
  - 容器内 root 用户修改文件需注意权限
  - 敏感数据（API Key）使用环境变量
  - 生产环境不要使用开发容器
