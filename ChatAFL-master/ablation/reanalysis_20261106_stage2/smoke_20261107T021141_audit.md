## Coverage evidence boundary

`smoke_20261107T021141_evidence/coverage.json` is `INCONCLUSIVE` for 33/33,
with no hard failures. Each terminal report says `acceptance=complete`,
`coverage_complete=true`, and `n_unreplayable_ledger_entries=0`. However,
every terminal has zero `executed_input_witnesses`; the audit therefore reports
`no-ever-seen-input-witness-proof`. Baselines also have no explicit branch
identity set (`baseline-has-no-explicit-branch-identities`). The terminal branch
counts (roughly 277--505) must not be reported as a seed-subtracted coverage
gain.

## Decision

The batch passes execution/ledger smoke, but it does not pass the coverage
evidence contract. It cannot establish Q1/Q2/Q3 contribution gains. Before
freezing the formal design, add the missing witness/seed identity chain and run
the absent Q1 reflow triplet and `cal_run_rate8`; then repeat the same archive
checks.
