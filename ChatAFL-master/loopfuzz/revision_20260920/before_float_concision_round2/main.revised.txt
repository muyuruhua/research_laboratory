        When Protocol States Mislead: Evidence-Gated Admission and Online Feedback
                       Calibration for LLM-Assisted Stateful Fuzzing

Abstract
Response-derived states offer inexpensive feedback for stateful protocol fuzzing, but state novelty is an imperfect proxy for
code progress. Requests generated by large language models (LLMs) can amplify this mismatch when unproductive proposals
receive durable mutation resources. We present LoopFuzz, an evidence-calibrated controller design combining execute-before-
promote admission with online state-productivity calibration. Bounded trials separate structural validity, response acceptability, and
reachability from code and inferred protocol state machine (IPSM) novelty. Code-supported candidates qualify for durable admission;
state-only candidates receive provisional validation and expire without subsequent code evidence. Discounted Beta–Bernoulli
updates and Thompson sampling combine estimated code productivity with frontier exploration, without claiming to recover
semantic protocol states. An audit of 628 archived runs across nine targets provides descriptive coverage, cost, and mechanism
measurements. Observed code-branch and IPSM state-edge endpoints do not consistently reproduce the hypothesized mismatch
across motivating targets. Four vulnerability case studies add replay evidence; controlled rediscovery benefits remain unmeasured. A
five-arm evaluation protocol specifies matched model configurations, intervention policies, and resource ceilings to isolate admission
and calibration. Heterogeneous observation horizons and incomplete lifecycle evidence restrict current findings to descriptive results.
Keywords: Stateful protocol fuzzing, Large language models, Response-derived state feedback, Evidence-gated admission, Online
productivity calibration
