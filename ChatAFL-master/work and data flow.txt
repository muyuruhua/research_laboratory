ChatAFL的工作流和数据流：

一、工作流程

1. 初始化阶段

从种子语料库加载初始的网络协议消息序列
通过LLM提取协议的语法规则(grammar)和消息类型
识别协议的状态转换模式

2. 种子丰富(Seed Enrichment)

分析现有种子中缺失的消息类型
通过LLM生成缺失的消息类型样本
将新生成的消息组合扩展种子库
3. 主循环模糊测试

从队列中选择种子消息序列
应用结构感知的变异操作(基于LLM提取的语法)
向目标服务器发送变异后的消息
收集代码覆盖率和状态覆盖率反馈

4. 高原突破(Plateau Breaking)

检测覆盖率停滞(plateau)
收集当前执行历史和状态信息
通过LLM生成针对性的新消息尝试达到新状态
重试机制确保生成有效性

二、数据流

输入侧：
种子消息 → 协议分析 → LLM提取语法/类型 → 存储为结构化规则

变异侧：
种子 → 结构感知变异(基于语法) → 变异消息 → 目标服务器 → 响应反馈

反馈侧：
服务器响应码 → 状态识别 → 代码覆盖率 → 评估是否保存新种子

LLM交互侧：
高原检测 → 构造提示(协议+历史+状态) → LLM生成假设消息 → 验证并重试 → 新种子入队

核心创新点：
ChatAFL将传统AFL的随机变异改为LLM引导的智能变异，通过三个LLM组件(语法提取、种子丰富、高原突破)实现协议感知的模糊测试，无需人工编写协议规范。
